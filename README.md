# 진선미 재가장기요양기관 공식 웹사이트

> 강원특별자치도 강릉시 주문진읍에 위치한 국민건강보험공단 지정 공식 재가장기요양기관 **진선미센터**의 반응형 웹 애플리케이션입니다.

---

## 🌟 주요 기능
- **기관 소개**: 최미선 센터장 및 이상현 시설장 프로필, 1급 사회복지사/요양보호사 전문 인력 및 시설 인허가 정보
- **서비스 안내 및 급여비용 계산기**:
  - 방문요양, 방문목욕, 가족요양, 복지용구 지원 안내
  - 장기요양 등급별(1~5등급) 본인부담금(일반 15%, 감경 6%~9%, 기초수급자 0%) 자동 실시간 계산기
- **장기요양등급 자가진단**: 어르신 신체/인지 상태 자가 문진 및 예상 등급 확인
- **1:1 간편 상담 접수 & 카카오톡/전화 연결**:
  - 온라인 간편 상담 접수 API 지원
  - 터치 시 다이렉트 전화 연결 및 카카오톡 오픈채팅 연동
- **오시는 길 & 네이버/카카오 지도 연동**: 강릉시 주문진읍 센터 위치 안내 (Leaflet 지도 탑재)

---

## 🛠 기술 스택
- **프론트엔드**: HTML5, Tailwind CSS, Vanilla JavaScript, Material Symbols
- **지도 라이브러리**: Leaflet.js / OpenStreetMap
- **백엔드**: Node.js 내장 `http` 모듈 기반 경량 웹 서버 (`server.js`)

---

## 🚀 로컬 실행 방법

Node.js가 설치된 환경에서 아래 명령어를 실행합니다:

```bash
# 로컬 웹 서버 실행
node server.js
```

브라우저에서 `http://localhost:3456` 또는 `http://127.0.0.1:3456`으로 접속합니다.
